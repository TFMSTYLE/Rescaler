# Changelog

## 1.0.1

The source code is now in this repository, with the license it has always been released under.

- Added the GPL 3.0 license text and a copyright notice
- Changed the extension id from rescaler to tfmstyle_rescaler so it cannot clash with another addon. If you have an older copy installed, remove it first
- The package now lists exactly which files it holds
- Shortened the tagline to fit Blender's 64 character limit
